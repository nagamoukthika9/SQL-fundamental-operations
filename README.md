# Basic SQL SELECT – Northwind Dataset

## Objective
The objective of this task is to practise basic SQL queries using SELECT, WHERE, and ORDER BY statements.

## Dataset
Northwind Sample Database.

## Tools Used
- MySQL
- MySQL Workbench

## Tasks Performed
1. Retrieved all records from the Customers table.
2. Selected specific columns from the Customers table.
3. Filtered customers based on country.
4. Retrieved products with a price greater than 20.
5. Displayed products that are not discontinued.
6. Sorted products by price in descending order.
7. Sorted products alphabetically by name.
8. Filtered orders based on shipping country.
9. Sorted orders by date.
10. Retrieved the first 10 customer records.

## SQL Concepts Used
- SELECT – To retrieve data from tables.
- WHERE – To filter records based on conditions.
- ORDER BY – To sort records in ascending or descending order.
- LIMIT – To restrict the number of records displayed.

## Deliverables
- SQL query file containing 10 queries.
- Northwind sample dataset.
- Query outputs.

## Conclusion
This task helped me understand basic SQL operations and practise retrieving, filtering, and sorting data using MySQL.
